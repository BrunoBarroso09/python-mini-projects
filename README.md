## 📌 Guess the number
✔️ **Game description** – This is a strategy game developed in Python, where the main challenge is to discover a secret number between 1 and 20 before running out of lives. At the start, the player receives 5 health points and must enter their guesses successively. With each incorrect attempt, the program provides immediate feedback, indicating whether the number entered is greater or less than the correct value, helping the player adjust their logic for the next move. Each mistake results in the loss of a life point, and the game ends when the user guesses the number correctly, or when the life reaches zero, revealing the hidden number in a defeat scenario.
